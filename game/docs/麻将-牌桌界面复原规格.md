# 麻将牌桌界面复原规格（对标《明星三缺一 2004》）

> 参考：BV1gb411y7XN，游戏窗口内容区 **778×552**。
> 本文所有坐标都写成「参考像素」，实现时统一乘 `S = 720 / 552 = 1.3043` 并加水平偏移 `OX = 133`，
> 即 `screen_x = 133 + ref_x × 1.3043`、`screen_y = ref_y × 1.3043`（`theme.py` 里已按此表落值）。
> 桌布另行向左右铺到画面外，不参与这套映射。

## 一、结论

复原的难点不在“画得像”，在**三件结构性的事**上，缺一件就不像：

1. **桌面是一块铺满下半屏的暖玫瑰色绒布，没有木边、没有侧边可见**——桌沿就是画面里那条把人物切开的横线。
2. **牌是竖立的**：牌顶面（亮）在上、牌面（白）在下、投影在牌脚。不是平放的纸片。
3. **左右两家的牌顺着桌布斜边斜着码**，每张牌还各自转了 20° 左右；四家牌墙围成一圈。这是“像一张真牌桌”的关键。

## 四、牌的画法（竖立）

- 牌身 = **牌顶面（亮，高 ≈ 0.13×牌高）+ 牌面（白）+ 牌脚投影**；顶面在上，不是在下。
- 牌背同构：顶面更亮一档，下面是洋红牌背（pitch 比牌宽小 2~6 px，视觉上叠在一起）。
- 丢弃的牌同样竖立，只是更小（28×32 级）。

## 七、与原图必然的差异（不是 bug）

- **人物立绘**：按需求删除。原图上半部是三个真人立绘，我们这里只剩名牌，
  所以画面上方 110 px 是“房间墙面”，不是空。
- **背景照片**：原图是实拍照片，我们是程序化生成的模糊暖色（不引入图片资源）。

2. 局间小游戏（拉霸/商店）的界面；

## 九、验收口径

- 与参考同高并排看，**桌面色相、牌的高宽比、四家牌墙围成的环形**三样必须一眼对得上；
- 单帧 ≤ 10 ms（当前牌桌 4.4 ms）；
- 牌面在白底纸卡上缩小到 30% 仍能分辨花色与点数。
